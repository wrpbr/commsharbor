# CommsHarbor

Transactional email and permission-based campaigns in one accountable harbor, with multi-tenancy and audit built in.

## O que faz

* Transactional email with idempotent sends, delivery tracking and dead-letter replay
* Permission-based marketing campaigns: audiences, templates, consent and suppressions
* Sending domains verified live against SES and DNS, with deliverability feedback
* Multi-tenant organizations with members, invitations, scoped API keys and webhooks
* Tenant CRM and platform CRM kept apart, with contacts, exports and deletion requests
* Audit trail and delivery accountability
* Agent-first HTTP API

## Preço

* 30-day organization trial: one sending domain, 1,000 contacts, 5,000 sends, webhooks, API keys and the audit trail: grátis
